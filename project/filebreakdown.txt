COUCHY — PROJECT ARCHITECTURE & FILE MAP
================================================================================

ARCHITECTURE & KEY INVARIANTS
- Stack: React 19 + Tailwind CSS v4 SPA served by Express + better-sqlite3 (`server.ts`).
- Primary System Workflow (`src/server/workflows/primary_workflow.json`):
  - Node #30_19: User Prompt | #30_27: Seed | #30_3: Sampler | #49: Aspect Ratio & MP
  - Node #30_10: Diffusion Model (UNETLoader) | #50: Power Lora Loader | #30_23: LoRA toggle
  - Node #51/#52/#53/#54: Inline 4x ESRGAN upscale; for target > 3.0 MP, Node #49 stays at
    3.0 MP and Node #51 switches on to scale to target MP in #52 in a single ComfyUI pass.
- Standalone Upscale: Inspector Upscale (`POST /api/images/:id/upscale`) compiles
  `src/server/workflows/upscale_workflow.json` and copies source metadata to the derived image.
- ComfyUI Polling: All `/history/:promptId` completion tracking routes through
  `src/server/services/comfyuiPoller.ts` (`pollComfyPromptCompletion`).
- Persistence: User annotations (`ratings`, `tags`, `collections`) are keyed by SHA-256
  `content_hash` so directory scans preserve them if image files move.

ENTRY POINTS & SHARED
- `server.ts` — Express server, API route mounting, chokidar/periodic scans, Vite middleware.
- `package.json` — Scripts (`dev`/`start`: `tsx server.ts`, `build`, `lint`: `tsc --noEmit`) & deps.
- `Dockerfile`, `docker-compose.yml`, `.env.example` — Container runtime & env config.
- `src/api/client.ts` — Typed HTTP client (`api`) wrapping all `/api/*` endpoints.
- `src/shared/types.ts` — Shared TypeScript interfaces across frontend and backend.
- `src/shared/utils.ts` — Aspect ratio presets, byte formatters, prompt interpolation, model filters.

SERVER: CORE, WORKFLOWS & ROUTES
- `src/server/config.ts` — Runtime path/URL/API-key resolver (`appConfig`) & `ensureDirectories()`.
- `src/server/db.ts` — SQLite schema/migrations (v1–v9) and default workflow/template seeding.
- `src/server/workflows/primary_workflow.json` — Primary Krea2_turbo API graph (with #51–#54 upscale).
- `src/server/workflows/upscale_workflow.json` — Standalone single-image upscale API graph.
- `src/server/routes/imagesRoutes.ts` — Gallery query, thumbnails/files, annotations, ZIP export, upscale, WD14 tag actions.
- `src/server/routes/charactersRoutes.ts` — Character CRUD, merges, LoRA/workflow links, assisted ID suggestions.
- `src/server/routes/generationRoutes.ts` — Prompt templates, LM Studio endpoints, image interrogation, `/submit-batch`.
- `src/server/routes/modelsAndWorkflowsRoutes.ts` — ComfyUI status, LoRA Explorer, model sync/search/downloads, workflow CRUD & reproduction.
- `src/server/routes/systemRoutes.ts` — Health, runtime config, scans, tags/collections/presets, backups, WD14 tagger controls.

SERVER: SERVICES
- `src/server/services/workflowCompilerService.ts` — Deterministic API graph compiler for primary & upscale workflows.
- `src/server/services/comfyuiPoller.ts` — Unified `/history/:promptId` poller, output indexer, and error/timeout handler.
- `src/server/services/comfyuiService.ts` — ComfyUI connectivity, model inventory sync, reproduction & upscale submission.
- `src/server/services/comfyuiLiveMonitor.ts` — WebSocket `/ws` + `/queue` monitor building live ghost preview cards.
- `src/server/services/scannerService.ts` — Chokidar watcher, recursive indexer, 384px WebP thumbnails, prompt/seed linking.
- `src/server/services/pngMetadataParser.ts` — PNG chunk (`prompt`, `workflow`, `parameters`) metadata & LoRA/model parser.
- `src/server/services/galleryQueryService.ts` — Boolean search parser, batch image hydration, series collapsing, filters, sort modes, LoRA aggregation.
- `src/server/services/seriesService.ts` — Image iteration series/stack persistence, middle-of-stack branching, upscale stacking, exclusive poster favorite.
- `src/server/services/characterService.ts` — Character profile builder, transactional merge, heuristic auto-matching engine.
- `src/server/services/lmStudioService.ts` — LM Studio photo-set prompt generator, 10-turn Quick Gen Conversation & hybrid Vision/WD14 interrogation.
- `src/server/services/visualTaggerService.ts` — Local WD14 v3 ONNX Runtime keyword tagger & background queue.
- `src/server/services/modelManagerService.ts` — Civitai & Hugging Face model search and SHA-256-verified `.part` downloader.
- `src/server/services/backupService.ts` — SQLite binary snapshots (`PRAGMA integrity_check`) & JSON annotation export/restore.
