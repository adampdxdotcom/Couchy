# Couchy — Project File Breakdown
# Updated: 2026-11-23

## Root & Configuration
- server.ts — Express HTTP server entry point, API router mounting, startup migrations/services, and Vite/static SPA serving.
- index.html — Vite HTML entry template.
- package.json — Dependencies, npm scripts (dev, build, lint, test), and TypeScript/Node configuration.
- tsconfig.json — TypeScript compiler configuration.
- vite.config.ts — Vite bundler configuration.
- metadata.json — Applet metadata and capabilities.
- Dockerfile — Production container image definition.
- docker-compose.yml.example — Example Docker Compose deployment configuration.
- .env.example — Documented runtime environment variables (paths, ComfyUI/LLM URLs, optional API keys).
- README.md — User guide, installation instructions, Civitai integration guide, and technical reference.

## Frontend Core & Hooks (src/)
- src/main.tsx — React root entry point.
- src/App.tsx — Top-level application shell, workspace routing, modal coordination, and Quick Gen integration.
- src/index.css — Global Tailwind CSS import and theme styling.
- src/api/client.ts — Typed frontend REST client for all `/api/*` endpoints.
- src/hooks/useAppToasts.ts — Ephemeral toast notification queue and message log state.
- src/hooks/useCivitaiNotifications.ts — Persistent header Civitai activity notifications (likes/comments) and mark-seen state.
- src/hooks/useGalleryImageActions.ts — Rating, favorite, reject/undo, delete, and bulk gallery mutation handlers.
- src/hooks/useLiveStatusPolling.ts — Live ComfyUI generation status, ghost card polling, and download status sync.
- src/hooks/useWorkspaceData.ts — Central workspace data loading and refresh hook (images, characters, models, workflows, presets).

## Shared Contracts & Utilities (src/shared/)
- src/shared/types.ts — Shared TypeScript domain interfaces (images, models, LoRAs, characters, Civitai drafts, workflows, presets).
